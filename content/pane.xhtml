Zotero IMA 同步

将 Zotero 条目 PDF 同步到腾讯 ima 知识库（ima.qq.com），构建可检索的文献 RAG 库。

认证 · IMA Skills API Key（推荐）

获取方法：登录 ima.qq.com/agent-interface （或 ima 客户端左下角头像 → 设置 → IMA Skills / 开发者选项）→ 生成 API Key → 复制 Client ID 与 Api Key。 有效期约 1 个月，过期后重新生成即可。这正是 WorkBuddy「ima 知识库」连接器所用的凭证方式。
（如需使用旧版 Bearer token，可在本框或插件设置面板「高级」中填写。）

目标知识库

也可点击「获取我的知识库」自动列出可选库并填入。
同名文件再次同步时的处理方式。建议首次同步用 SAVE，重复同步用 REPLACE。
仅当在插件设置面板「高级」中改用 Bearer token 时才生效（默认 IMA Skills API Key 模式无需关注此选项）。
